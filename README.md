# Data Analyst Copilot

An AI-first data analysis workspace. Ask questions in natural language and let the copilot choose the right output: insight, table, chart, or diagnostic.

## MVP
- Demo sales dataset
- CSV upload
- Natural-language intent routing
- Top 10 ranking
- Group comparison
- Hot-product insight
- Diagnostic view
- Responsive UI
- Ready for OpenAI integration

## Run locally
```bash
npm install
npm run dev
```

Then open http://localhost:3000.

## Roadmap
Google Sheets / Drive, Excel, Supabase projects, semantic metrics, deterministic DuckDB query layer, OpenAI agent/tool calling, saved analyses and exports.
